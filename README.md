# 面团猫桌宠 MVP

一个 Windows 2D 小桌宠原型：小小的面团猫会待机呼吸、眨眼、偶尔自己走动；点击或按住拖动时会像软面团一样变形，并用文字气泡回应你。

## 运行

```powershell
python main.py
```

也可以在 Windows 里直接双击 `run_pet.bat`。

项目只使用 Python 自带的 `tkinter`，不需要额外安装依赖。

## 已实现

- 透明悬浮窗口
- 默认置顶
- 2D 面团猫绘制
- 待机呼吸和随机眨眼
- 偶尔短距离走动
- 左键点击显示文字气泡
- 左键按住/拖动时软弹变形
- 右键菜单：置顶、暂停走动、隐藏气泡、切换外观、重置位置、退出
- `Esc` 快速退出

## 操作

- 左键点一下：猫猫回应一句话
- 左键按住或拖动：rua/移动猫猫
- 右键：打开菜单，可以切换奶白猫/小黑猫外观
- Esc：退出
